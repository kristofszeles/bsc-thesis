\chapter{Felhasználói dokumentáció} % User guide
\label{ch:user}

A felhasználói dokumentáció olyan segédletet nyújt a felhasználó számára, amely nem igényel programozói ismereteket és könnyen elsajátíthatóvá válik a szoftver használata. Részletes leírást ad a futtatásról, a funkciók működéséről és a konfigurálhatóságról.

A játékmotor egy labirintusjátékot valósít meg, amelyben egy- vagy több játékos bolyonghat véletlenszerűen generált labirintusokban, vagy a pályaszerkesztővel készített egyedi pályákon. A szoftver két fő egységre bontható: A kliensoldalon futó játékprogramra (\verb|maze-game|), valamint a szerverprogramra (\verb|maze-server|). Ezen fő egységek bővebb leírása a következő alfejezetekben (2.2, 2.3) lesz olvasható.

\section{Rendszerkövetelmények}

A szoftver az implementációnak köszönhetően multiplatformos, azaz több különböző rendszeren is futtatható. Elsősorban Windows és Linux rendszereken teszteltem a működését, de számtalan más rendszerre is könnyen átfordítható a megfelelő eszközök segítségével. A program fordításáról a fejlesztői dokumentációban (3. fejezetben) esik szó.

Minimális hardverkövetelmények:

\begin{itemize}
	\item Legalább 2 magos 2 GHz-es processzor (Intel vagy AMD)
	\item Minimum 4 GB belső rendszermemória
	\item OpenGL 3.0 (vagy későbbi) támogatottsággal rendelkező videokártya
\end{itemize}

Szoftverkövetelmények:

\begin{itemize}
	\item Windows operációs rendszer esetén Windows 7 vagy újabb kiadás
	\item Linux operációs rendszer esetén elsősorban Debian alapú rendszerek (például Ubuntu, Linux Mint)
\end{itemize}

Debian alapú rendszereken program a következő csomagokat igényli a futtatáshoz:

\begin{itemize}
	\item libsdl2-2.0-0
	\item libsdl2-image-2.0-0
	\item libsdl2-net-2.0-0
	\item libglew2.1
\end{itemize}

\subsection{Konfiguráció}

A játékprogram konfigurációját a \verb|game-config.json| fájl tárolja. Ha a fájl nem létezik, akkor a program automatikusan létrehozza az alapértelmezett beállításokkal. A fájl az indításkor betöltődik, ami meghatározza bizonyos komponensnek működését. Kilépéskor a fájl mentésre kerül, azaz a felhasználó beállításai perzisztens módon ''megjegyzésre'' kerülnek. A fájl a következő konfigurációs paramétereket definiálja:

\begin{itemize}
	\item \verb|game|: játékmotor beállításai
	\begin{itemize}
		\item \verb|cameraFov|: kamera látószögének mérete fokokban
		\item \verb|renderDistance|: látótávolság sugara egységekben
		\item \verb|mouseSensitivity|: egérérzékenység (0.1 és 1.0 közötti érték, 0.1 - leglassabb, 1.0 - leggyorsabb)
		\item \verb|vehicle|: aktuálisan kiválasztott jármű típusának száma
		\item \verb|singlePlayer|: egyjátékos mód beállításai
		\begin{itemize}
			\item \verb|score|: játékos pontszáma a legutóbbi játékban
			\item \verb|health|: játékos életereje a legutóbbi játékban
			\item \verb|highScore|: eddigi legnagyobb pontszám
		\end{itemize}
	\end{itemize}
	\item \verb|maze|: labirintusgenerátor beállításai (\verb|easy|, \verb|medium|, \verb|hard|)
	\begin{itemize}
		\item \verb|width|: labirintus szélessége
		\item \verb|height|: labirintus magassága
	\end{itemize}
	\item \verb|multiplayer|: többjátékos mód beállításai
	\begin{itemize}
		\item \verb|defaultHost|: szerver hosztneve (IP címe)
		\item \verb|defaultPort|: szerver portszáma
		\item \verb|playerName|: játékos neve
	\end{itemize}
	\item \verb|window|: programablak beállításai
	\begin{itemize}
		\item \verb|defaultWidth|: az ablak alapértelmezett szélessége
		\item \verb|defaultHeight|: az ablak alapértelmezett magassága
		\item \verb|maximized|: az ablak maximalizálva van-e
	\end{itemize}
\end{itemize}

\subsection{Egyjátékos mód (Single Player)}

Egyjátékos módban a felhasználó (játékos) egy megadott nehézségű, véletlenszerűen generált labirintusban bolyonghat és különféle kincsek felszedésével pontokat gyűjthet. Azonban a játékos nincs egyedül: A pályán számítógép által irányított járművek (NPC-k) furikáznak, amelyekkel ütközve a játékos életerőt veszít. Ha az életerő eléri a nullát, akkor a játék véget ér (Game Over) és az elért pontszám megjelenik a képernyőn az eddigi legjobb pontszámmal együtt, ezt illusztrálja a 2.2 ábra.

\subsection{Többjátékos mód (Multiplayer)}

Többjátékos módban több felhasználó is részt vehet egy labirintusjátékban. Először a játékos nevét kell megadni, ami alapján azonosítható lesz a pályán. Az \verb|ENTER| gomb lenyomásával lehet a következő képernyőre lépni, ahol kiválasztható egy jármű, amelyet a többi játékos fog látni, ez lesz a játékos ''karaktere''. Végül a szerver IP címét és a portszámát kell beírni kettősponttal elválasztva, ahova a kliens csatlakozni fog. A \verb|CTRL+V| billentyűkombinációt alkalmazva beilleszthető a vágólap tartalma, így nem szükséges kézzel begépelni a hosszú címeket.

Lehetőség van más, eltérő játékosokkal és labirintussal rendelkező szerverekre is csatlakozni. Csatlakozás után mindenki ugyanabban a labirintusban vesz részt és a játékosok látják egymás karakterét, tudnak versenyezni, hogy ki fogja előbb megtalálni a kijáratot. A kijárat megtalálása a lehető legtöbb pontot éri. Emellett a pályán szétszórt kincsek felszedésével is tudnak bónusz pontokat gyűjteni.

\subsubsection{Toplista}

A 2.5 ábrán is látható, hogy a bal felső sarokban található a toplista, amely a szerver által számontartott játékosok pontszámait tartalmazza sorszámokkal ellátva. Legfelül, az első helyen az eddigi legtöbb pontot elért játékos található, utána a többi, csökkenő sorrendben. A pontszámok listája automatikusan frissül, amint valaki pontot szerez, belép, vagy kilép a játékból. Ha egy játékos kilép a szerverről, akkor a pontszáma törlődik és a következő belépésnél újra kell kezdenie a játékot.

\subsubsection{Chat ablak}

A képernyő bal alsó sarkában található egy chat ablak, ahol a legutóbbi 5 másodpercben fogadott 5 üzenet látható. Itt jelennek meg a szerver által küldött üzenetek (például ha egy játékos csatlakozott, vagy megnyerte a játékot). A játékosok küldhetnek egymásnak saját, rövid chat üzeneteket is, így a játék közben tudnak írásban beszélgetni. Ezt a \verb|T| (talk) gomb megnyomásával lehet kezdeményezni. Ilyenkor megjelenik egy szövegmező, ahova beírható a küldeni kívánt üzenet, majd az \verb|ENTER| gomb lenyomásával elküldhető. Az \verb|ESCAPE| gombbal pedig bezárható a chat ablak, az üzenet elküldése nélkül.

\subsection{Pályaszerkesztő (Map Editor)}

A beépített pályaszerkesztővel tetszőleges felépítésű pályák készíthetők kétdimenziós nézetben. Működése leginkább egy rajzprogramhoz hasonló, viszont itt képpontok helyett blokkok (falak, tárgyak stb.) rajzolhatók a képernyőre. A használathoz nem szükségesek különösebb ismeretek, csupán elegendő az egér használata.

A képernyő alján található menüsoron lévő gombokkal vezérelhető a program működése, illetve ezen funkciók a billentyűzet segítségével is elérhetők. A kiválasztott típust görgetéssel (fel/le) lehet változtatni. A megjelenő blokkok közül az ''N'' betű az \verb|NPC|-ket jelöli. Nagyobb pályák építése esetén a kamera mozgatható az egér mozgatásával a középső gombot nyomva tartva.

\section{A szerverprogram (maze-server)}

A szerverprogrammal lehetőség van játékszervert hosztolni. A program futhat a játékprogram mellett, nem feltétlenül kell külön gépen futnia, valamint a játékprogramot (vagyis a klienst) futtató operációs rendszer is eltérhet a szerverprogram rendszerétől. A program használata észszerű: Indítása után elindul a konfigurációban megadott portszámon, majd elkezdi fogadni a csatlakozó játékosokat.

\begin{figure}[H]
	\centering
	\includegraphics[width=1\textwidth]{server.png}
	\caption{A szerverprogram konzolablaka futás közben}
\end{figure}

A program visszajelzi a felhasználónak a sikeres indulást (\verb|Server is now running on port XXXXX|). Ellenkező esetben egy felugró hibaüzenetben jelzi a hiba pontos okát, amiért nem tudott elindulni. A szerver IP címe mindig a futtató gép IP címével egyezik meg, lehetőség van az interneten keresztül is csatlakozni a megfelelő tűzfalbeállítások mellett.

Induláskor a szerverprogram véletlenszerűen generál egy labirintust, amelyet a játékhoz való csatlakozáskor elküld a játékosnak. Amint valaki elérte a célt, a program új labirintust generál.

\subsection{Konfiguráció}

A szerverprogram konfigurációja a \verb|server-config.json| fájlban van tárolva. Ha a fájl nem létezik, akkor a program automatikusan létrehozza az alapértelmezett beállításokkal. A könnyebb átláthatóság kedvéért JSON \cite{json} formátumot alkalmazok, amely egy kulcs-érték párokat tartalmazó objektum. A fájl a következő konfigurációs paramétereket tartalmazza:

\begin{itemize}
	\item \verb|maze|: labirintusgenerátor beállításai
	\begin{itemize}
		\item \verb|width|: labirintus szélessége
		\item \verb|height|: labirintus magassága
	\end{itemize}
	\item \verb|server|: szerver beállításai
	\begin{itemize}
		\item \verb|port|: portszám, amelyen a szerver figyelni fog
		\item \verb|maxSlots|: maximális slotok (helyek) száma
		\item \verb|mapFile|: a használni kívánt egyedi pályafájl elérési útvonala
	\end{itemize}
\end{itemize}

A \verb|mapFile| kitöltése esetén a szerverprogram megpróbálja betölteni a pályafájlt a megadott elérési útvonalról. Ha sikeresen megtalálta, akkor induláskor új labirintus generálása helyett a fájlban tárolt pályát fogja betölteni.
