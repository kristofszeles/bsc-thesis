Maze Game.app — double-click to play (single-player or multiplayer client).

Maze Server.app — hosts multiplayer games. macOS does not attach a terminal to
double-clicked console apps, so start the server from Terminal instead, for example:

  "<path-to-this-disk>/Maze Server.app/Contents/MacOS/maze-server"

Use the disk image’s mount folder (shown in Finder) instead of <path-to-this-disk>.

Drag Maze Game.app into Applications if you like, then eject this volume.
